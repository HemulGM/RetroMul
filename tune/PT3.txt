PT3 / YM2149F support
====================
RetroTune registers .pt3 in the decoder registry and open-file filter.
Supported: Pro Tracker 3.x (3.3-3.7 tested), Vortex Tracker II headers, all four
note tables with historical variants, historical volume tables, ornaments,
samples, envelope/noise, tempo, glissando, portamento, vibrato and offsets.
TurboSound: mirrored patterns in one module, two concatenated modules with
02TS footer, and three concatenated modules with 03TS footer. Nested mirrored
modules in a concatenated container are rejected.

Default playback: 50 Hz, 1.7734 MHz YM2149F, ABC stereo, 44100 Hz 16-bit PCM.
The first complete pass ends at the module loop boundary. A tracker-only scan
computes exact duration; the existing player seeks by replaying and discarding
PCM. Volume and spectrum visualization use the existing PCM path. The scan is
bounded to 30 minutes to reject corrupt/unbounded input.

The replay engine is adapted from Volutar's MIT-licensed C version of Bulba's
PT3 player: https://github.com/Volutar/pt3player
Copyright (c) 2023 Volutar. License is preserved in LICENSE.PT3Player.
The port uses managed arrays/records and explicit byte/word wrap helpers with
Q+/R+ enabled, replacing raw word reads and pointer arithmetic. The C version's
envelope-slide precedence/sign bug is corrected against the original Z80 CHREGS
and Vortex Tracker's signed byte accumulator:
https://github.com/Volutar/vortextracker/blob/TS3/ZXAYHOBETA/VTII10bG.asm
https://github.com/Volutar/vortextracker/blob/TS3/trfuncs.pas

VGM/VGZ supports YM2149 type $10, register writes $A0, dual chips, header clock,
SEL divider, mono or ZX panning. Other AY-family types retain explicit rejection.

Verification tools and logs are in codex-work. BuildRetroTune.ps1 -Test runs
PT3 replay/malformed/EOF tests and, when present, independent C golden traces
for all test modules and native YM2149 channel levels. Tests are built with
overflow and range checks enabled for Win32 and Win64.
